# Contributing to Prompt OS

## Before changing code
- Identify the user-visible outcome.
- Read the relevant architecture and skill instructions.
- Define acceptance criteria.

## While changing code
- Prefer small, bounded changes.
- Preserve working behavior.
- Add tests for new domain behavior.
- Do not introduce secrets.

## Before declaring work complete
- Run the relevant tests/checks.
- Review changed files.
- Verify acceptance criteria.
- Record remaining limitations.
